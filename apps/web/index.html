Algorithm & Pipeline

How Multilateral Netting Works

Instead of requiring immediate onchain gas transfers for every micro-transaction, NORN coordinates peer obligations through a three-stage mathematical lifecycle.

STAGE 01 // SIGN

Cryptographic Obligation

Agents authorize machine service requests using EIP-712 structured data and HTTP x402 headers. Zero gas spent upfront, zero token movements required.

STAGE 02 // ROUTE

Cycle Cancellation

The NORN graph engine identifies circular debt loops across thousands of counterparties (A owes B, B owes C, C owes A) and collapses redundant paths.

STAGE 03 // SETTLE

Atomic Finality

Net debtor positions are settled atomically on Arbitrum Sepolia or Robinhood Chain in USDG / USDC, backed by cryptographic Merkle state roots.
